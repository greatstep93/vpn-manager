# Инструкция

Это небольшое приложение для обновления правил маршрутизации на openWRT Роутере настроенным с помощью скрипта от https://github.com/itdoginfo

Написано чтобы при настройке дополнительных правил не нужно было копаться в терминале и вспоминать где какие правила написаны. 

Приложение умеет добавлять/удалять домены на которые нужно ходить через VPN

По факту вносит правки в файл:

```/etc/config/dhcp```

добавляя домен в список для маршрутизации

Так же умеет добавлять/удалять ip на которые нужно ходить через VPN 

Вносит правки в файл:

```/etc/config/firewall```

Так же отображает список доменов загруженный по умолчанию скриптом от itdoginfo для информации.

После применения изменений перезапускает firewall чтобы обновить правила маршрутизации при удалении ip/доменов, поэтому первое время могут долго подгружаться например youtube
Так как там судя по всему много доменов используется при открытии и нужно дать время роутеру все зарезолвить. 

Также при обновлении списка доменов - ваше клиентское устройство не сразу начнет ходить через VPN, но это ограничение не данной утилиты.
Так как все устройства кэшируют DNS запросы они не сразу понимают что надо сходить к роутеру и узнать как именно нужно ходить по тем или иным доменам. 
Самый простой вариант это перезагрузить устройство, так же иногда помогает отключить-подключить сеть или войти/выйти из авиа режима чтобы сбросить DNS кэш на клиенте.
